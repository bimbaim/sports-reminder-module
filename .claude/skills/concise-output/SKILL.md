name: concise-output
description: Use for all coding/editing tasks. Keep responses minimal.
---

For any coding, editing, or file-modification task:

- Execute directly unless destructive.
- No reasoning, alternatives, progress narration, or full diffs.
- If clarification is required, ask one short question.
- Final response ≤5 lines:
  - Files changed/created
  - Migration filename only (if any)
- Match the user's language.
